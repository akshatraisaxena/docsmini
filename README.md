# 📄 DocsMini

**DocsMini** is a simple notes app built using **ReactJS** and **Tailwind CSS**.  
I created this project while learning React to practice component structuring, state management, and styling using Tailwind.

---

## ✨ Features

- 📝 Create and manage personal notes
- ✏️ Edit existing notes
- 🗑️ Delete notes
- 💾 Data stored in local state (no backend)
- 📱 Fully responsive UI

---

## 🛠️ Tech Stack

- **React JS**
- **Tailwind CSS**
- **Vite** 

---

## 🚀 How to Run

1. **Clone the Repository**
```bash
git clone https://github.com/akshatraisaxena/docsmini.git
cd docsmini
```
2.Install Dependencies
```bash
npm install
```
3.Start the development server
```bash
npm install
```
